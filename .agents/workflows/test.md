# 🧪 运行与补充测试 (Test Suite)

运行工作流进行单元测试。

## 1. 执行测试
后端测试代码在 `packages/api/src/__tests__/`。
```bash
turbo test
```
// turbo-all

## 2. 修复失败测试
- 判断测试用例出错原因是业务代码被破坏还是测试的 Mock 环境发生了变化。
- 使用 `vi.mock()` 更新过时的打桩数据。

## 3. （可选）编写新特性的测试
如果添加了新功能，请引导我在补充一份针对 Service 或 tRPC Router 边缘情况的单测用例。
