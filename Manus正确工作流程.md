## 关键交互

### 钩子

| 钩子 | 何时触发 | 做什么 |
|------|---------|--------|
| **SessionStart** | Claude Code 会话开始时 | 通知技能已就绪 |
| **PreToolUse** | 写入/编辑/Bash 操作前 | 读取 `task_plan.md` 以刷新目标 |
| **PostToolUse** | 写入/编辑操作后 | 提醒更新阶段状态 |
| **Stop** | Claude 尝试停止时 | 验证所有阶段是否完成 |

### 2次操作规则

每 2 次 view/browser/search 操作后，你必须更新 `findings.md`。

```
操作 1: WebSearch → 记录结果
操作 2: WebFetch → 现在必须更新 findings.md
操作 3: 读取文件 → 记录发现
操作 4: Grep 搜索 → 现在必须更新 findings.md
```

### 阶段完成

当一个阶段完成时：

1. 更新 `task_plan.md`：
   - 更改状态：`进行中` → `完成`
   - 标记复选框：`[ ]` → `[x]`

2. 更新 `progress.md`：
   - 记录执行的操作
   - 列出创建/修改的文件
   - 记录遇到的任何问题

### 错误处理

当发生错误时：

1. 记录在 `task_plan.md` → 遇到的错误表格
2. 记录在 `progress.md` → 错误日志并标注时间戳
3. 记录解决方案
4. 永远不要重复相同的失败操作
