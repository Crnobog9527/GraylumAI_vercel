只允许 `node packages/db/tests/erasure-completion/run-local.mjs --local-only`。
需要本机 Docker unix socket，使用仓库固定 PostgreSQL 镜像摘要；不接受远程连接或凭据。
`--local-only --development` 只用于开发，不代替完整历史位置重复回放。

完整文件建库、每项可重复迁移的历史位置重复执行；0190/0191 与0192分别验证空事实精确回退。
产生清理/进度事实后拒绝回退，只能向前修复，不能恢复已删除正文。
使用真实 service_role RPC 和实际 TypeScript processor；只有 Storage/Auth 适配器是注入模拟。
覆盖原财务行与身份保真、未知账务阻塞、正文/业务叶子分批清除、旧会话消费不被 CASCADE 删除、
上传跨网络意图、独立连接屏障、受限进度和 Auth 不确定结果。全部对象与数据是本机构造。

## 当前启用边界

- 没有实际删除 worker、cron 或真实 Storage/Auth SDK 适配器接线；不会自动执行整账户删除。
- 上传路由需要0190先就绪；其超时意图不自动过期或重发。实际启用清理前须排空旧版本未记意图的上传，
  并确认所有实际上传及引用入口经过新准入规则；本机测试不能证明部署已排空。
- Storage manifest 必须来自可信业务附件表，并对全部主体做完整引用检查；未知/共享/旧URL不自动删除。
- 原退款批准、手续费依据和旧生成/Slice未投影证据保持受限待复核，保留原金额、hash及幂等身份。
  每30天只是内部复核提醒，不自动放行/退款/结清，不改Gold/IP未定保留规则。
- 进度凭证是首次确认返回的32字节随机能力，数据库仅存哈希；待处理期间有效，完成后30天过期；访问有效期不是内容留存期限。
  当前提供后端POST查询；尚未将凭证保存/展示接入前端。无凭证不通过公开requestId查询。
- `completed` 仅表示本服务在线业务范围的前提及模拟/注入Auth不存在确认，不代表备份、日志平台或第三方已清。
  真实部署、第三方与日志/备份留存仍须另行授权和有效证据。
