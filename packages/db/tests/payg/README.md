# PAYG PR-A 本机 SQL 回归

运行完整专项：

```sh
node packages/db/tests/payg/run-local.mjs --local-only
```

入口只接受本机 Docker Unix socket，使用仓库锁定且已存在的 PostgreSQL 镜像，
`--pull=never`，端口只绑定 `127.0.0.1`。不读取数据库 URL、不调用模型或外部支付。
每次创建自己的随机名容器，并在成功或失败后删除该容器和卷。

完整模式复用 `buildFromFiles`，从空库按真实文件顺序建库，并在每个迁移的历史位置
连续执行两次、逐对象比对结构。`--local-only --development` 仅用于同范围修复迭代，
跳过历史逐迁移指纹重放；它不能替代完整模式或仓库要求的 baseline replay。

0162 在首次应用前注入提交前失败，核对完整目录回退；应用后分别篡改一个来源函数及本次修改的两个目标函数，验证 md5 拒绝漂移且恢复后目录一致。

测试复用既有 B2a/inflight 的 v1 fixture 和全部原用例，再覆盖：

- 六个旧公开收尾入口对 v1/run 和 v2/call 预扣全部拒绝；普通旧钱包六入口保持可用。
- v2 零 run 预留、call hold、门槛、累计一次进位、封顶、重复回执和收尾幂等。
- 名义计价、缓存费用偏差、长上下文、分时最高价、实际费用兜底和三次查账上限。
- 确认故障对已结算前缀的补偿及未知后续退款；迟到证据不重扣。
- 注销后的未派发撤权、未知费用 hold、已结算前缀、零 call 和错误预扣绑定。
- 真实双数据库连接的重复领取、跨 run 争余额、重复回执/收尾及取消竞争；同账户/窗口、不同模型的 prepare/claim 与 dispatch/claim 锁顺序竞争。
- 计费投影允许/拒绝权限、平台承担和实际/名义差额恒等式。
- grant 过期、逆转、终止、隔离；混合模型倍数、充值不补收 E、大小和缺字段边界；直接验证 quote 缺失或 NULL 的输入/输出/context 上限会拒绝。
- MAINT-P4 可用余额一处算（0391，`credit-available.mjs`）：`credit_available` 的值（可为负，调用方取 0 下限）；领取和预扣共用它；重复领取只建一条；拒付冻结的终止 grant 不再被领取重复扣留；拒付途中的保留；待复核 grant（含已冻结的）两条路径都拒绝；同账户两连接并发领取不会动用被保留的积分。

- FUSION-REVIEW 计费组（0234，`fusion-group.mjs`）：整组余额不够时一个调用都不建、够时各单满额冻结；重复组领取幂等、换内容冲突；
  普通领取拒绝 Fusion 用途和组内运行单；每个运行单只一次调用；没有判定不结算、判定只写一次；两连接并发结算组内运行单，各自取整（Owner 2026-10-14）；超出冻结额的调用封顶在自己的冻结额、结算顺序不影响总额；组领取先拿模型锁再锁组不死锁；只删内容不注销时保留冻结；
  未结算运行单不挡其他运行单；format_invalid 零收费全退；注销后组内全部运行单零收费结算；入组后不能改组。

- RESEARCH-TOOLS 工具调用计费（0255，`research-tools.mjs`）：冻结额 ceil(U·q·m)、有官方用量按冻结单价收费、模型和工具在同一运行单只进位一次；
  缺用量、结果未知、确认失败、200 报错平台承担四种情况都对用户按 0 当场结算、释放冻结、运行单继续，供应商成本分开记"待确认"或"已确认"；
  回执必须和冻结单价一致、每次调用只收一份结果、重复提交不重扣；报价校验（价格、上限、用途、过期）；余额封顶和超用量停线路；
  派发后没有结果到恢复期限按未知结算；对账补记供应商成本；staging 测试窗口；两连接并发领取和并发回执；注销时立即释放；函数权限。

  缺少默认 m 行都在准备时拒绝；关闭开关、移除线路、换密钥、停用模型、去掉标记都挡住下一次领取；有启用的测试窗口时正式模式关闭；
