# Frontend Design Skill

This skill enables creation of **distinctive, production-grade frontend interfaces** that reject generic AI aesthetics.

## Core Approach

The methodology emphasizes intentional design thinking before coding:

1. **Contextual Analysis**: Understand purpose, audience, and constraints
2. **Bold Aesthetic Direction**: Choose a clear visual philosophy—from "brutally minimal" to "maximalist chaos"—and execute with precision
3. **Production Implementation**: Deliver functional, visually striking code

## Key Design Principles

### Typography & Visual Identity
- Prioritize distinctive, characterful font selections over defaults
- Pair display fonts with refined body typefaces
- Use CSS variables for cohesive color systems with dominant hues and sharp accents

### Motion & Interaction
- Favor orchestrated, high-impact animations (CSS-preferred for HTML)
- Employ staggered reveals and scroll-triggered effects
- Focus on meaningful micro-interactions over scattered effects

### Spatial Composition
- Embrace asymmetry, overlap, and diagonal flow
- Break grid constraints with intentional unconventionality
- Balance generous whitespace or controlled density contextually

### Atmosphere & Depth
- Layer textures, gradients, and decorative elements
- Avoid solid color backgrounds in favor of contextual visual effects

## Critical Guardrails

Avoid overused conventions:
- Generic font families (Inter, Roboto, system fonts)
- Clichéd color gradients
- Predictable layouts
- Cookie-cutter patterns

Each design should reflect its unique context.
