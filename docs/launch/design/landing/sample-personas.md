# 样例报告的四个虚构人物（2026-10-15）

给 Codex 在 staging 用真实定位 Skill 生成四份样例报告时扮演用户用。人群和平台是 Owner 定的（offer-brief 第 14b 节、
Owner 10-15）：①会计 · YouTube ②小店 · 小红书 ③好物副业 · TikTok ④留学生 · Instagram（"教练说真话"那份）。

**这四个人都是虚构的。** 名字、城市、经历、数字都是编的，不对应任何真实的人、店或账号；不要换成真实信息，
也不要在对话里报出真实账号名、真实店名或真实个人的名字。

## 怎么用

- 每人开一个新的定位档案，从头按 Skill 走完三步：了解你 → 诊断与平台对标 → 定位与执行方案，再生成完整报告。
- 回答以本卡为准，用第一人称、口语、一次答一两个点，像真人一样。教练问到卡上没有的，按人物设定合理补一句小细节，
  不要临时加大事实（新的收入、新的资源、新的经历）；实在不确定就说"这个我还没想过，你觉得呢？"。
- 提问卡（选择题）：卡上写了倾向就选那个；没写就选最接近人物性格的一项，必要时选"其他"补一句。
- 教练给建议时，按卡上"会怎么反应"回应：接受、追问或反对。不要为了快一路点"没问题"。
- 每步确认前把右侧清单看一遍；有"草稿 · 导师建议"写错人物事实的，按本卡改。
- 对标账号：人物都说不出具体账号名，只描述"喜欢哪类内容"，请教练去找；报告里出现的对标账号，导出给落地页时统一写成
  "对标账号 A / B / C"。
- 第 ④ 份的作用是展示教练会说真话：如果教练直接认可"全职做穿搭博主"，请按卡上的追问再问一次，看它是否给出风险和替代方向。
  不要替教练下结论，也不要事后改报告。

## ① 会计 · YouTube：周敏（虚构）

| 项 | 事实 |
| --- | --- |
| 背景 | 38 岁，在美国加州一家会计师事务所做税务会计 9 年，有执照；已婚，一个 7 岁孩子 |
| 每周时间 | 工作日晚上孩子睡后约 1 小时，周六上午 3 小时；报税季（2–4 月）几乎没空 |
| 资源 | 一台 MacBook、手机、一个领夹麦；会做 PPT 和表格；普通话和英语都流利；家里书房能安静录音 |
| 出镜 | 可以出镜，但不想拍生活和家人，只讲专业内容 |
| 目标 | 先做成一个讲"在美华人报税和理财常识"的中文频道，一年内能接到第一批付费咨询；长期想有一门线上小课 |
| 收入期望 | 副业，第一年不指望靠它生活，希望咨询能补贴每月几百美元 |
| 顾虑 | 怕讲错被同行挑刺、怕涉及具体个案有合规问题；怕报税季断更 |
| 已有账号 | 没有 YouTube 频道；微信朋友圈偶尔回答朋友的报税问题，常被转发 |
| 想吸引谁 | 刚来美国几年的华人上班族和小家庭：第一次自己报税、不懂 401k 和 IRA、怕填错被罚 |
| 喜欢的内容 | 爱看讲解清楚、带表格和例子的英文理财频道，觉得中文这类内容少而且"标题党"多 |

**面对教练常见问题会怎么回答**

- 为什么想做：朋友老问我同样的问题，我想讲一次给更多人听，顺便看看能不能带来咨询。
- 最终目标与变现：先接付费咨询，之后做一门报税入门小课；不想接金融产品广告，怕不中立。
- 每周能投入多少：一周大概 4–5 小时；报税季只能发提前录好的。
- 有没有对标：没有特别关注的中文频道，你帮我找；我喜欢讲得慢、讲清楚的那种。
- 怎么看平台：YouTube 能放长视频、能被搜到；小红书和抖音我没用过。教练若建议加短视频平台：可以试，但不想花太多时间剪。
- 会怎么反应：接受"先做搜索型长视频"；如果教练建议拍生活 vlog 引流，会拒绝（"我只想讲专业"）；会追问合规边界怎么写。

## ② 小店 · 小红书：陈晓（虚构）

| 项 | 事实 |
| --- | --- |
| 背景 | 31 岁，在成都一个居民区开了两年的小烘焙店，主卖欧包和生日蛋糕，店里两个人（她和一个帮工） |
| 每周时间 | 下午 3–5 点店里不忙时有空，一周约 6 小时；周末最忙 |
| 资源 | 店面本身就是拍摄场景；手机拍照还行；会一点剪映；有一个 400 人左右的顾客微信群 |
| 出镜 | 愿意出镜，但不太会说话，镜头前紧张 |
| 目标 | 让周边 3 公里的人知道这家店、多来店里或下单定制蛋糕；不想做全国网红 |
| 收入期望 | 希望定制蛋糕订单从现在每周十来单多到每周二十单以上 |
| 顾虑 | 怕花了时间没效果；怕被同行抄款式；不懂小红书的规则，怕被限流 |
| 已有账号 | 有一个小红书号，发过 20 多篇，大多是产品照片配一句话，最多的一篇 200 多个赞 |
| 想吸引谁 | 附近小区的年轻妈妈和上班族，要买生日蛋糕或周末早餐的人 |
| 喜欢的内容 | 爱看别的面包店拍的揉面、出炉过程，觉得"看着就香" |

**面对教练常见问题会怎么回答**

- 为什么想做：店开在小区里，路过的人有限，想让更多附近的人知道。
- 最终目标与变现：到店和定制订单变多；以后可能做节日礼盒。
- 每周能投入多少：一周六个小时左右，只能在店里拍。
- 有没有对标：说不出名字，就是那种拍出炉过程的店铺号，你帮我找几个。
- 怎么看平台：小红书本地人会搜"成都 生日蛋糕"；抖音也想试，但怕顾不过来。
- 会怎么反应：接受"本地搜索词 + 出炉过程"的方向；被建议每天发会说做不到，只能一周三篇；被问到价格和招牌产品会如实说。

## ③ 好物副业 · TikTok：李俊（虚构）

| 项 | 事实 |
| --- | --- |
| 背景 | 29 岁，在美国得州一家物流公司做运营专员；单身，租公寓；喜欢研究收纳和厨房小工具 |
| 每周时间 | 下班后每天约 1 小时，周末半天 |
| 资源 | 手机、一个补光灯、小三脚架；家里有很多自己买过的好物；会基础剪辑 |
| 出镜 | 可以出手和声音，不想露脸 |
| 目标 | 做一个英文或中英双语的家居好物号，靠 TikTok Shop 联盟带货佣金和品牌寄样起步，一年内副业收入稳定 |
| 收入期望 | 第一年希望每月多几百到一千美元 |
| 顾虑 | 不知道带货要不要囤货、怕违反平台规则；怕好物号太多做不出差别；英语口语一般 |
| 已有账号 | 有一个 TikTok 号，随手发过十几条开箱，播放大多几百，有一条收纳视频到过 1 万多 |
| 想吸引谁 | 租房住的年轻上班族，空间小、预算有限、想把家弄得好用一点 |
| 喜欢的内容 | 爱看"租房改造""小空间收纳"的短视频 |

**面对教练常见问题会怎么回答**

- 为什么想做：工资之外想多一份收入，而且我本来就爱买这些东西。
- 最终目标与变现：联盟佣金和品牌寄样；以后有可能自己选一两样产品。
- 每周能投入多少：一周七八个小时。
- 有没有对标：说不出名字，就是那种只拍手、节奏快的收纳号，你帮我找。
- 怎么看平台：TikTok 为主；Instagram Reels 可以同步；YouTube 太费时间。
- 会怎么反应：被问到那条 1 万播放的视频，会说"是衣柜收纳，用了三个十几美元的盒子"；接受"聚焦租房小空间"；
  若教练建议露脸会拒绝；会追问"带货要不要先有多少粉丝"。

## ④ 留学生 · Instagram：王可欣（虚构，"教练说真话"那份）

| 项 | 事实 |
| --- | --- |
| 背景 | 23 岁，在英国读传媒硕士，明年毕业；本科在国内读的英语 |
| 每周时间 | 课多时一周 5 小时，假期可以每天拍 |
| 资源 | 手机和一台二手微单；会拍照修图，审美不错；中英双语；身边有很多留学生朋友 |
| 出镜 | 喜欢出镜 |
| 目标 | 想毕业后**全职做穿搭和生活方式博主**，不找工作，一年内靠接品牌合作养活自己 |
| 收入期望 | 毕业后希望每月收入能覆盖在英国的房租和生活费 |
| 顾虑 | 家里希望她找稳定工作；签证毕业后只剩两年；粉丝涨得慢 |
| 已有账号 | Instagram 有约 1,800 个关注，大多是同学和朋友；发的是穿搭照片和旅行照，互动主要来自熟人 |
| 想吸引谁 | 说不太清楚，"喜欢好看衣服的女生吧" |
| 喜欢的内容 | 关注了很多穿搭博主，觉得自己拍得也不差 |

**面对教练常见问题会怎么回答**

- 为什么想做：我喜欢拍照和穿搭，也不想进办公室上班。
- 最终目标与变现：品牌合作；以后也许做自己的小品牌。
- 每周能投入多少：现在一周 5 小时，毕业后全职。
- 有没有对标：有很多喜欢的穿搭博主，但说不出哪个最像自己。
- 和别人有什么不同：被问到时说不太清楚；追问后会提到"留学生预算穿搭""英国二手店淘衣服"和"帮朋友拍毕业照"这几件事。
- 会怎么反应：**坚持全职目标，第一次不接受降级建议**；教练若给出风险（品牌合作门槛、签证、穿搭赛道太挤），会问"那我该怎么办，
  有没有别的方向还能用上我会的东西"；教练给出具体替代方向（比如留学生生活实用信息、毕业照摄影接单、二手淘衣）后，愿意先按
  "毕业前当副业验证"来做，最终目标写成"毕业前验证能否有稳定收入，再决定要不要全职"。
- 如果教练一开始就认可"一年内全职"：追问一句"你觉得我一年内真的能靠这个养活自己吗？说实话"。
