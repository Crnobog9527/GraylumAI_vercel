实现说明

  • 首月资格由服务端判断：账号在任何渠道都没买过 Gold，就选 Waffo 的"新用户"产品（订阅用"前 N 期特价"），否则选正价产品；前端只显示服务端返回的价格。
  • 创始名额由服务端计数：剩余数实时读取；结账开始时先占，没付成功就释放；全额退款放回，主动取消或续费失败不放回。年付标签"最高省 40% / 25%"也按名额状态切换。
  • 积分包折扣按会员档位由服务端计算后返回，前端只显示。
  • 只显示已上线的功能：评审团两种模式、多平台发布、数据监控、资料库容量，都按后台开关显示；还没上线的功能不写进权益，或标"即将上线"。
  • 报告预览只显示用户已确认的信息和章节说明，不调用模型；"示例片段"必须来自演示账号并标明是示例。步骤和章节取自定位 Skill 2.6.0，实现时从当前绑定的 Skill 读取。
  • 到期弹窗的数字（档案、资料、复盘次数）从用户真实数据读取；某项为 0 就不显示那一项。
  • 划线价只用真实价格；不做假原价、不做重置倒计时；续费说明写在付款按钮旁边。
  • 规划要同步的：D4 改为评审团 Gold 专属；第 50 项删掉"Pro 买 2 次积分包提示 Gold"；积分包会员折扣、客服时效、内测优先；多平台发布和数据监控提前到上线前（会改变 D1 的上线范围）。
