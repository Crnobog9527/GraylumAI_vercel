# LIB-2a 后端交接

风险 high：数据库、私有资料权限与删除；不合并、不操作远程存储或数据库。
依据 `LIB_DOCS_PLAN.md` 第 2、3、4.3、5、7、8 节及 #770 总控核对。

## 范围与完成条件

实现四张领域表、私有桶、原子额度、txt/md 分段、图片原样保存、本人签名读取、
立即拒读与清理、默认关闭开关、薄 tRPC 和独立清理 cron。
本机 PG17 空库/重复迁移、并发屏障、权限拒绝、上传/清理/注销与工单回归均需实际验证。
不改前端提取、计费和 Runtime，不新增解析依赖。Agent 读取和识别计费另属后续任务。

## 设计约束

复用会员计划作为额度唯一来源、profiles 行锁串行额度、现有 cron 鉴权和运行记录。
四张领域表是方案指定的文档、分段、上传占用和识别单元；不建立第二套账本或队列。
直传每个可写路径先占桶上限 10,000,000 字节，空间不足拒绝。
签名可能有效时不重新发同请求的令牌；删除后仍保留最大写入占用，直到两小时令牌期限
加一小时在途宽限期之后，两次独立存储确认无对象。失败不释放。
