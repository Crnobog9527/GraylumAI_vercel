## 4. 执行合同与风险处理

### 资格、金额和人工审批

- 普通规则覆盖首次会员（月/年/创始/一次性会员合同）、积分包、Pro 升 Gold；续费不可退。
  以权威付款时间判断 7 天，不用下单时间；采用精确 UTC 168 小时边界，等于边界仍允许申请；判定时点取可验证的工单提交时间。
- 工单及时提交的申请保留申请时间证据，避免管理员处理延迟把及时申请变成超期；
  无法确定该工单申请对应哪笔订单时先核对。审批与执行前仍重新查消费、拒付、重复退款与金额。
- 任意来源消耗过 1 积分即拒绝普通退款；不以“其他来源先扣”放行。已消费后返还不能仅凭净额为零放行。
  在途/未知结算不得当作零消耗，先沿原机制核对；不得修改 BILL2 计费核心或派发 AI 调用。
- 按原实际成交、折扣和币种最小单位计算，整数运算；按已确认断言，费用向下取整到最小货币单位，
  净额 = 可退基数 - 费用，以免舍入超过 6%；不得超过原实收减已成功退回金额，不按现价退款。
  此舍入及边界已由主窗口审计固定为测试断言；不引入可配置手续费。
- 仍保留第 51 项“法律允许”的约束，无法确认适用时进入人工核对，不由代码推断司法辖区。
  例外退款中未用已购积分折现、税费分摊若现有合同无明确依据，单列金额明细交主窗口确认，
  不自行用现价或统一积分汇率创造商业规则；不阻塞普通路径的独立实现。
- 管理员批准绑定订单、工单、理由类别、金额、资格证据及版本；用户不能写批准字段。
  执行前原子核验仍有效；并发审批只能有一个可执行意图。工单文字本身不成为财务授权。

### 原渠道执行与结果未知

- 核验原交易、商户、模式、币种及同主体归属；不跟随后台当前销售渠道切换。
  Waffo/未知渠道在此片明确未支持，不能落到 Stripe 执行。
- 拒付订单、已退款订单、未决退款不得再发起现金退款；审批失败、查找失败、权限失败均零调用。
- 先落稳定执行身份，再按同一幂等身份执行；超时/未知先查原交易与退款结果，不换身份重退。
  webhook 比 API 返回先到、重复和乱序均复用原核对机制；失败不能伪装完成。
- 现金只退扣费后净额，但首购/积分包/升级的积分处理按商品规则完整执行。
  不伪造 fullRefund 金额事实来触发回收，也不能只因现金不足原价而漏终止/少收回积分。
- 执行期间与消费/发放并发时沿既有来源保护和事务锁处理；外部成功、本地失败进入待核对，
  重放只补本地一次效果，不发第二笔现金。未授权外部退款也必须按权威事实记录并待人工核对。

### 各类型权益处理

- 首购：结束对应会员、停止续费及未来发放，收回本次已发积分；年付 7 天内回收首月，
  创始身份立即结束且名额不回池。积分包回收该包积分及其购买赠送，不动其他来源。
- 升级：只退该笔 Gold 付款，回收 8,970；Pro 原到期日前恢复剩余期限、不改变到期日、不恢复扣费，
  年付剩余月份按原锚点发到原到期日，并提供到期前重新订阅提醒。原到期日之后不恢复期限。
  原完整期限必须由 source_order_id 的 invoice 映射核对或补不可变证据；
  不把年付 p01 period_end、当前 Gold 期末或推算一年当作原期限。缺失/冲突/多来源时停止自动恢复。
  如补期限快照，仅改支付升级局部并用本机 fixture 验证，不远程补写历史数据。
- 功能大幅缩减/无故终止：不受 7 天或已消费限制，按剩余服务时间退，结束会员及未来发放；
  功能缩减不收回已经发放的积分。无故终止另退未用已购积分，逐来源核实并防止与时间退款重复计价。
- 违规终止：不退款，积分使用权作废，保留账务，不借退款恢复登录或重新注册资格。
  现有封闭主体判断仅约束原账号，开户赠送身份摘要也不能证明新账号被禁止购买。
  **整体完成阻塞**：同一已违规终止身份重新注册后仍不得恢复资格，这项尚无可用证明。
  PR-4B 必须盘点现有身份机制并提交最小接线及保留规则供主窗口审计，不能擅建新身份系统。
  在同身份换号的拒绝测试、正常不同身份的允许测试、注销后的保留/清理边界通过前，
  PR-4 不得标为整体完成；4A 纯资格计算可独立交付，不能替代该权限证明。
- 注销：账务必要证据保留到交易年度末起 3 年，不存工单正文/附件于财务 metadata，
  不因工单删除级联删除账务；迟到支付或退款事实仍记账，不能复活账号、会员或自动退现金。
