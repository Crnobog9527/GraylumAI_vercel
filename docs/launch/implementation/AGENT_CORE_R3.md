## 实现与安全边界

- 声明格式：`organizerTemplate: assets/organizer-template.md`，可选、包内相对 Markdown 路径，最大 3,000 字节。
- 通用模板见 `services/skills/organizerTemplate.ts`；定位沿用现有的 `opc/organizerPrompt.ts` 字段提取协议。
  未声明的定位旧包保持原提示词不变；普通 Skill 使用现有 Runtime 通用整理语义。
- 声明保留在不可变包内，不复制到数据库 workflow，避免新增第二份配置权威；后台现有导入和发布接口可直接使用。
- 读取复用 `databaseSkillSource` 和完整性缓存，每次重新校验读取权限；仅取声明的模板，
  不把完整 Skill 原文交给整理模型。缺文件、撤销、哈希不符、非法编码或超长时拒绝，不悄悄回退。
- 宿主格式与字段保护规则优先；模板只补充整理指导。冻结进 `attachedOrganizer.instructions`，重放直接用原上下文。
- 风险 high：改变模型收到的指令；不改变账务、权限配置或数据库。撤回宿主代码前，应先停止向新草稿分配声明了新字段的包；
  不能在旧代码上继续读取新字段。旧草稿和已冻结执行不需要升级。
