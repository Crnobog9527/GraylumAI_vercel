# 账号定位报告（合成样例，仅供实测）

## 1. 账号基本情况
博主"小林的厨房实验室"，在小红书和 YouTube 发布家常菜教程，目前小红书 3200 粉丝，YouTube 800 订阅。
本人是在美国工作的华人程序员，每周能稳定拍 2 条视频，预算每月 200 美元以内。

## 2. 目标受众
主要受众：在北美生活、25–35 岁、刚开始独立做饭的华人留学生和职场新人。
次要受众：想给孩子做中餐的华人家长。
受众痛点：买不到国内调料、厨房设备和国内不同、下班后时间少。

## 3. 内容定位
一句话定位："用美国超市就能买到的食材，30 分钟做出家乡味。"
内容支柱：
- 平替调料（用美国超市食材替代国内调料）
- 一锅出 / 空气炸锅快手菜
- 每周备餐（meal prep）

## 4. 差异化
同类账号多数在国内拍摄，食材在北美难买；本账号所有食材都来自 Costco、Trader Joe's、H Mart。

## 5. 变现路径
第一阶段：品牌合作（厨具、亚洲超市）。
第二阶段：付费电子食谱（9.9 美元）。
第三阶段：线上烹饪课（49 美元）。
报告中没有说明每个阶段的粉丝门槛和预计收入。

## 6. 发布节奏
小红书每周 2 条图文 + 1 条视频；YouTube 每周 1 条长视频、3 条 Shorts。
当前每周可用时间只够做 2 条视频，节奏和产能可能冲突。

## 7. 九十天目标
小红书到 10000 粉丝，YouTube 到 3000 订阅，拿到第一个品牌合作。
