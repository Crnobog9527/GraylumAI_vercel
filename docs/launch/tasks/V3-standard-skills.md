## 产品目标与不可省略的语义

- 标准目录保存独立文件，元数据发现、显式绑定、完整入口、按需读取方法与模板；禁止将整包展平为单条 published_content 后冒充目录运行。管理员私有导入/导出，普通用户只取得允许的界面字段和自己的成果。
- 普通聊天按请求读取当前发布版本；工作台轮次固定 `revision + package hash + workflow schema + template hash`。新轮次默认继承旧包，升级明确展示方法变化并重新确认受影响成果。每次执行仍查实时权限、模块启停、Skill 归档、版本撤销；历史成果可读与私有包可执行分开。
- 首个社媒模板的六步保留需求确认、对标分析、定位、内容规划、运营、变现的业务顺序。以界面保存/确认取代斜杠命令。AI 候选、可编辑工作稿、不可变确认快照分开；版本冲突保留未保存输入，迟到 AI 只成为候选。
- 前序修改、采用新证据或更换包按声明依赖使受影响的当前/下游确认待复核，保留内容与旧快照；可沿用并重新确认，不强迫重生成。仅获取未采用的候选证据不使全部成果失效。
- 社媒模板保留同账号一个项目、至多一个 active draft 的规则。v2 草稿不改变当前正式 v1；全步骤有效确认后，原子、幂等地产生唯一递增版本和正式报告，再切换当前执行指针。放弃草稿不改 v1；恢复旧方向通过新轮次，不覆盖历史。
- 社媒模板报告先保存页面编辑，再验证六步最新确认；从同一快照确定性汇编需求背景、对标、定位、内容、运营与变现、来源/局限、版本说明。默认不调用模型；站内排版和 Markdown 导出忠实保留用户确认内容，重新下载不创建新版本。
- 策略差异绑定改变原因与当时证据；实践复盘绑定观察窗口和当时采用策略，没有实践资料只报告差异与证据不足。不同平台、窗口与指标分母不可假装可比。
- Skill 搜索/取数经全站受控服务端数据层，首选 AgentKey MCP + API Key，采用官方 SDK；不同时建设未经核实的 REST 路径。模型供应商搜索旁路在未来接线时关闭，普通非 Skill 聊天不默认迁移。
- 工具发现、执行前 schema/价格复核、允许能力、有限研究计划、预算、逐次调用与检查点由宿主控制；不向模型/浏览器开放任意工具、shell、URL 或凭证。结果未知先核实实际状态，不盲重试。首批不实现 MCP。
- 证据记录用户/项目归属、稳定对象身份、来源、获取/观察时间、样本/分页、缺失原因、指标口径、内容 hash 与保留条件；供应商返回、用户补充和修订分开。到期或删除传播到展示与导出，不以历史不可变绕过期限。
- 供应商成本与用户积分分开；取数和分析独立持久化/计量，分析失败不重新取数。复用原钱路与原子预留/结算，不建第二套余额。执行前校验权限/包/输入/预算；结果、费用与成果关联必须幂等且可恢复。用户价格、总预算及使用条款在外部启用前另行确认。
- 私有包正文/manifest/Key 不进公开接口、前端包、普通日志。模型看见方法后仍存在诱导复述风险，不承诺零泄露；密钥与权限裁决不交给模型。真实包须在未来权限修复与非生产验证后私有导入。

## 通用 Skill 与可配置工作台

### 共享机制与配置边界

Graylum 建设共享 Skill 基座和配置驱动的多步骤工作台。社媒六步是首个业务模板，不是平台固定结构。在已支持能力范围内，新 Skill 主要通过方法包和经校验的流程配置接入；仅因步骤数、业务名称、问题或报告章节变化，不应修改核心页面、存储结构、保存/确认接口或报告代码。真正新增的能力通过受控、可复用的模块扩展，不复制一套系统。

- 共用项目/轮次/步骤成果、AI 候选、工作稿、确认快照、依赖复核、历史版本、证据、确定性报告、权限及费用机制。
- 业务配置表达步骤数量、稳定步骤标识、展示顺序、依赖、输入/成果约束、方法资源、必需能力、完成条件和报告映射。配置是经过校验的数据，不是任意代码或可执行表达式；技术文件名、schema 和接口由相应实施任务确定，本节不宣称它们已经存在。
- 三步、六步、八步使用同一核心：导航、服务端校验、编辑/保存、确认条件、依赖失效传播及报告汇编都使用该轮固定流程定义。通用核心不得写死六个业务字段、六个页面分支或“完成六步”常量；不得仅把导航数量做成可变就算完成。
- 宿主可以声明合理的容量限制，不承诺无限步骤；不扩展为任意脚本、无限循环或通用可编程自动化平台。现有 loader 的 `tasks` 是资源读取映射，不是已经实现的工作台流程定义。

### 业务、版本与隔离语义

- 社媒模板保留需求确认、对标分析、定位、内容规划、运营、变现的原顺序、成果及完整报告要求；它们由社媒配置表达，不强加给其他 Skill。
- AI 候选、用户工作稿、不可变确认快照分离；迟到 AI 不覆盖用户编辑，版本冲突不丢弃未保存内容。修改上游、采用新证据或升级方法后，按声明依赖标记受影响确认待复核，保留内容与旧快照，不强迫无关步骤重做。
- 轮次固定方法包、流程定义和报告模板身份。新版本增删/重排步骤不静默改变旧轮次、旧确认或旧报告；方法升级须明确确认并复核受影响成果。v2 草稿不改变正式 v1；满足该轮定义的全部有效确认后原子、幂等生成正式版本；放弃草稿不覆盖历史，重复导出不创建新版本。
- 服务端按用户、项目、Skill、轮次和版本隔离读取、修改、确认、证据与恢复状态，同名步骤不能串数据。社媒“同账号一个项目”及 active draft 规则保留在适用范围；非社媒 Skill 不必提供社媒账号。此次不增加任意多项目、团队协作或跨 Skill 共享功能。
- 历史成果可读不代表已撤销/禁用的私有方法仍可执行。动态工作台仍执行实时权限、模块/包/版本状态检查；私有正文、manifest、凭证不进入普通用户接口，仅向前端投影允许公开的界面配置。

### 报告、能力与兼容范围

报告从该轮有效确认快照按固定模板确定性汇编，不强制非社媒 Skill 包含社媒章节，不默认调用模型。报告和导出仍忠实保留确认内容、来源及局限，沿用前述历史版本与确定性要求。

无研究需求的 Skill 不强制调用 AgentKey；需要研究/分析时复用受控能力、原钱路与持久恢复，取数与分析分别计量，不建第二套用户余额。包声明能力不等于获得权限、预算或证明供应商可用；未支持的必需能力须在外部调用和扣费前拒绝。

普通非工作流文档 Skill 无需补流程配置；只有使用多步骤网页体验时才提供宿主可校验的流程定义。不得宣称任意标准 Skill、Markdown、脚本或文件类型均能无适配运行；当前格式、资源读取、容量及安全边界保持有效。

## 本批实现契约

`packages/api/src/services/skills/` 是独立 Node/TypeScript 薄核心，不从 root/router 或聊天运行路径导出。无新路由、空业务服务、ZIP UI、脚本执行或 Codex 子进程。

- `SkillSource` 分开 `list / state / read`。目录列出 immutable descriptor；本地 adapter 只接受受控注册根目录，未来 DB adapter 复用接口但必须自己实施真实授权、撤销与不可变读取。当前回调只是测试状态，不能作为 DB ACL 通过证据。
- descriptor 绑定 package/revision/directory、完整文件路径/字节数/媒体类型/SHA-256、资源依赖、可选任务资源计划和必需能力；确定性 package hash 包含这些信息。每个 revision 唯一，重复或 hash 漂移拒绝。hash 证明完整性，不证明来源可信。
- fixture 的 `catalog.json` 在标准包之外，是本测试宿主注册信息；不是 Agent Skills 标准文件，也不是内部商业 manifest 的公开接口。生产注册信息只能来自受控服务端。非多步骤包无需 `tasks` 内容或任何社媒六步扩展。
- 宿主明确选择已审阅的资源计划。入口总是完整读取；无条件 `requires` 和任务根资源的依赖闭包完整读取，其他 reference 不读。多任务包必须选合法 task，无任务包直接读取入口依赖。不会让模型猜文件或把 Markdown 链接当自动执行命令。**本批不承诺解析任意自然语言/Markdown 引用**：包接入者须提供与方法一致的资源依赖；未来导入/发布器必须检查该映射，不能未经审阅把第三方目录标为完整支持。
- 发现阶段在本地读取入口提取元数据，但不加载参考文件或将入口正文放入目录。激活重新读取并校验原字节。必需资源缺失、无权限、禁用/归档/撤销、未知 task/身份、越界、链接、脚本/二进制及未知必需能力均明确失败，无名称或版本猜测。
- 路径使用规范相对路径；拒绝 `..`、绝对路径、反斜杠、编码路径、等价大小写路径、符号/硬链接。本地根目录由操作者控制，不能接受用户上传可并发改写的树；哈希与读前/后检查不等于通用敌对文件系统沙箱。
- 包 ≤64 文件、展开总字节 ≤2 MiB、最多64任务；目录 ≤256版本。方法容量按 UTF-8 字节及最终 JSON 包装计算，任何不足明确失败，不截断。未来模型适配器必须在扣除其他上下文/输出预算后按具体 tokenizer 再校验；本批没有模型 token 容量证明。
- `LoadedSkill.forModel()` 是唯一显式取得私有上下文的方法；它不是用户响应。默认 JSON/普通 inspect 仅投影 packageId/revisionId/name/description；内部资源标识通过独立方法取得。错误只含固定代码，不保留原始 YAML/文件错误 cause，不记录正文。公开名称与描述必须是可公开元数据，不能放商业原文。
- 不缓存用户授权。发现后仍重新检查执行状态，逐资源读取与最终返回前检查撤销；未来实际模型/收费取数入口必须再次检查当前授权，不能将这个本地结果当永久执行令牌。

## 标准校验与宿主兼容分开

以 [Agent Skills specification](https://agentskills.io/specification) 和其 [宿主指南](https://agentskills.io/client-implementation/adding-skills-support) 为格式参考；指南的宽松建议不覆盖严格发布约束。

| 输入 | 标准/本宿主处理 |
| --- | --- |
| 合法名称、描述、块标量、带冒号的合法 YAML | 成熟 `yaml` 库解析；两个真实样本通过 |
| 缺 name、名称/目录不符、超长描述、重复键或非法 YAML | 严格拒绝；返回固定诊断，不修复或重写原始待发布字节 |
| YAML alias | 本宿主不展开 alias；格式报告为未评估（null），兼容报告为不支持，不冒称严格格式已通过 |
| 未知可选元数据 | 原文保留，不因不认识而删除，也不因此授予能力 |
| `allowed-tools` 或环境要求 | 可满足格式要求，但本宿主不支持工具且不能自动确认环境，单独报告兼容问题 |
| 未支持的必需能力、脚本/二进制、非规范路径 | 宿主拒绝；并非声称 Agent Skills 标准禁止所有脚本 |
