# 正式定位到独立脚本：交付与验证

产品依据为已批准的两份 `docs/launch/proposals/account-artifact-*.md`。本批是有界实现，不改变原 M3/REL-1；PR #412 尚未获合并授权。部署配置、数据库与真实供应商均未修改。

## 实际实现

- 在正式 `/workbench` 定位报告内选择已配置脚本功能并命名作品；创建后进入原 `/chat`，沿用原 reply/summary、步骤保存、确认、正式报告与找回。
- 新作品为独立 project；修订为同 project 的新 round。旧定位唯一约束、旧无账号文档项目及单作品 active draft 保留。创建请求身份固定，重试不创建第二份。
- 账号关联来自源定位项目，不由浏览器另填账号；round 固定不可变 source version/hash 和配置 ID。采用不同定位版本时从空稿开始，旧正式版本不覆盖；同来源修订保留完整旧 provenance，确认必须重新完成。
- 引用是目标项目本地 evidence，源正文从既有正式版本确定性选取，不复制正文库。源报告的完整依赖、账号授权或引用映射失效会屏蔽依赖作品及对话的正文、采用、报告与导出。
- 可信结果保留金额及请求身份，按原事务幂等结算；无权限正文在迟到 receipt/candidate/request 写入前脱敏。unknown 保留预扣，不重派、盲退款或免单。
- 脚本显示固定定位版本及明确修订入口；不显示不能实际执行的“升级方法”。原普通项目的方法升级保留。异步创建/修订迟到后不切回已离开的项目。

## 验证范围与归属

执行者为本任务唯一 writer；独立完整审查另记录在 PR 的精确 base/head 下。运行使用现有一次性 Postgres 17、Auth、PostgREST、Next HTTP、Chromium 和可计数 loopback 模型替身。虚构三步脚本方法与六步定位，不包含真实私有方法。普通与文档模型调用同样只走本地替身。
