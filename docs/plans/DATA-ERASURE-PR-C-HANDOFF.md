### 第二片实现与恢复边界

0188 为四张既有公共账表新增单向清理标记、固定财务元数据投影和受限批量入口。
不替换金额/退款算法，不添加表、队列或自动调用。实际旧生成、研究、Slice、BILL2 v1/v2、
官方用量、搜索计价使用各自固定字段；来源 ID 和原始 number/string/null 保留，
正文、原始 response、搜索查询/来源页和任意嵌套载荷清掉。

每次只处理一张表，最多100条，跳过被锁行。异常类型保留原记录并返回 manualReview；
剩余行、异常行或锁忙都不能当作完成。服务端晚到合法写入继续用原账務函数，
已关闭账户的新正文被同一固定投影清除。关闭前已开始的事务仍须由后续协调器调用
既有事务屏障后再清理；本入口单独返回 remaining=0 不代表账户注销完成。

真实测试区分：已确认失败的合法补偿，与注销取消后收到的消费凭据；后者按原结果结算，
不能把取消当确认失败。原余额数值、消费分类、原预扣/消费身份及金额依据均不得重算。
空数据结构可以精确回滚；已有清理事实时拒绝回滚，只能向前修复。

仍未完成：支付/订阅元数据与异常回执的必要 B2b 收尾、PR-C 协调、Storage、资料假名化、
受限进度和 Auth 删除模拟。没有远端应用、启用、真实删除或付款操作。
