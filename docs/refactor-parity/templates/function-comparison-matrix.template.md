## 判定规则

- `一致`：旧站与新站的可见行为一致，足以认为功能颗粒度保持
- `部分一致`：主功能存在，但文案、状态反馈、边界行为明显不同
- `缺失`：旧站有，新站没有
- `有缺陷`：新站功能存在，但不能稳定完成目标
