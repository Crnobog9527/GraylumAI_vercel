# 旧仓库基线冻结模板

> 使用方式：查看旧版 GitHub 仓库代码、文档、截图和录屏，从中推断用户可见行为。不要要求自己还原全部技术实现，只记录“旧版本表达了什么产品行为”。

## 填写规则

- `旧仓库证据位置` 填文件路径、README 段落、截图文件、提交哈希或 issue 链接
- `旧版本操作步骤` 填从页面结构和按钮流程推断出来的用户动作
- `旧版本预期结果` 只写用户能看到的结果，不写底层实现
- `置信度` 只能填：`高` / `中` / `低`
- 如果完全无法从旧仓库推断，直接写“无法判定”，不要猜
