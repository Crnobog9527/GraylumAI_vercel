# 修复问题清单

> 使用方式：每发现一个差异，就按下面格式写成独立问题单，直接交给开发者。

## 严重级别定义

- `P0`：无法登录、无法聊天、后台打不开、关键数据错乱
- `P1`：主流程能走，但结果不对、按钮失效、状态误导、权限异常
- `P2`：体验退化、文案错误、加载态/空态/错误态不一致
- `P3`：样式细节、边角交互、非核心页面差异
