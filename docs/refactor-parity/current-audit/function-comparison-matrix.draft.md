## 当前结论

- 已确认的真实缺陷只有 1 项：公开落地页 hydration mismatch
- 已确认的结构性差异有 1 项：旧版是 Base44 托管登录入口，新版是公开落地页 + 站内 `/login`
- 最大阻塞不是代码，而是证据不足：缺少普通用户和管理员 E2E 账号，导致登录后首页、聊天、后台都还没有完成首轮一致性验收
