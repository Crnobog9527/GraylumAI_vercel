## 当前结论

- 这轮关键回归共 15 项，`12` 项通过，`3` 项失败
- 已确认的真实产品问题有 2 项：公开落地页 hydration mismatch、聊天发送链路被模型区域限制阻断
- 另有 1 项是测试规则问题：中断流式回复时产生的 `net::ERR_ABORTED` 被当前监控器当成阻塞错误
- 已确认的结构性差异有 1 项：旧版是 Base44 托管登录入口，新版是公开落地页 + 站内 `/login`
