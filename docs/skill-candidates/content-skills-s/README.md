## 四个包

| 包名 | 用途 | 触发意图（写在 description 里，匹配器只看 name 和 description） | 宿主提供的上下文 | 产出格式 |
| --- | --- | --- | --- | --- |
| `short-video-script` | 视频口播稿，连同标题、封面字、发布文案和话题标签 | 写 / 改口播稿、视频文案、脚本、台词、开头；"改短一点""更口语" | 定位、选题简报（选题窗口常驻；自由对话按需读取）。以前保存的稿子正文**不提供**：要改的稿子不在对话里时，Skill 请用户贴进来 | 一句话说明 → 标题 2–3 个 → 封面字 → 分段正文（标秒数、总时长、替换开头）→ 需要补的真实素材 → 发布文案和标签 → 下一步 |
| `video-storyboard` | 分镜：每段口播配什么画面、怎么拍、多长 | 出分镜、分镜脚本、这段拍什么、怎么拍 | 定位、选题简报；选题窗口里本轮附上**最新定稿口播稿**（声明来源 `script`）。自由对话不附，用对话里的稿子或请用户贴 | 一句话说明 → 分镜表（镜号、时长、对应口播原句、画面怎么拍、素材道具）→ 拍摄顺序 → 准备清单 → 新手提醒 → 下一步 |
| `video-editing-guide` | 剪辑建议：开头、节奏、画面切换、字幕、声音 | 出剪辑建议、怎么剪、字幕和音乐怎么弄 | 定位、选题简报；选题窗口里本轮附上**和当前口播稿匹配的最新分镜**（声明来源 `storyboard`），口播稿正文不另附。自由对话不附 | 一句话说明 → 整体风格 → 逐镜剪辑表 → 剪辑步骤清单 → 封面 → 发布前检查 → 下一步 |
| `post-and-article` | 图文笔记、多图帖子、长文章、短帖 | 写笔记、图文、轮播帖、公众号 / 知乎文章、改标题、正文太长 | 定位、选题简报（同口播稿）。以前保存的稿子正文**不提供**，要改的不在对话里时请用户贴进来 | 图文：说明 → 标题 → 图 1–N（画面、图上文字）→ 正文 → 标签 → 真实素材 → 下一步；长文：说明 → 标题 → 带小标题的全文 → 真实素材 → 下一步 |

四个包的共同规则：信息够就先写、缺关键信息才问一个带例子的问题；一条内容只做一件事；不编造用户的真实经历、客户、数据、成果和作品，只有这些才用【】留给用户填（食材、道具、场景这类创作选择由 Skill 自己定、写具体）；国内平台不站外引流、不用绝对化用语、提醒版权和隐私；不承诺播放量；输出语言以用户沟通用的语言为准，目标观众是英文时只在末尾提示可以出英文版（Owner 2026-10-24，Master Plan 第 2.1 节）；不说"已保存"，保存由用户在界面确认；对应的另一个 Skill 没加载时只提议下一步，不越界代写。

## 包结构和声明字段

- 每个包：`SKILL.md`（对话时加载的唯一文件，自成一体）+ `workflow.yaml`（固定字段）+ `EVALS.md`（验收用例，不进对话）。管理员发布时每个文件的 `requires` 为空（`modulePublication.ts`），所以不放需要另外读取的参考文件。
- `workflow.yaml` 按 G / A2 窗口（G #1026，A2 #1036；规则文档随 A2 写在 `docs/launch/implementation/CONTENT_SKILL_RULES.md`）给的格式写：`kind: document`，一步、资源只有 `SKILL.md`，不写 `information` / `profileKey`（写了会被当成定位类）。非定位 Skill 的这一步只作为工作顺序，不开强引导。

  | 包名 | `workflow.yaml` |
  | --- | --- |
  | `short-video-script` | `kind: document`；一步"写口播稿" |
  | `video-storyboard` | `kind: document`；`contentSource: script`；一步"写分镜" |
  | `video-editing-guide` | `kind: document`；`contentSource: storyboard`；一步"写剪辑建议" |
  | `post-and-article` | `kind: document`；一步"写图文或文章" |

- `contentSource` 只在选题窗口生效：选中分镜时注入本选题最新定稿口播稿，选中剪辑建议时注入和当前口播稿匹配的最新分镜；自由对话不注入，Skill 按用户给的内容写。
- 后台"与社交媒体相关"四个都选"是"（POSITIONING-GATE 用），不在包里声明。成果类型目前没有字段（属于 C1），不声明，未知字段会被拒。
